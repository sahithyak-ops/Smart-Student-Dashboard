# LUNERA - Smart Student Productivity Dashboard

Lunera is a simple full-stack student productivity dashboard built to help students manage tasks, subjects, study time, and productivity.

## Features

- Add and manage tasks
- Set task priority and due dates
- Mark tasks as completed
- Add subjects and track topic progress
- Normal study timer
- Save study sessions
- Weekly study analytics
- Productivity streak
- Simple dashboard interface

## Tech Stack

### Frontend
- HTML
- CSS
- JavaScript

### Backend
- Python
- FastAPI

### Database
- SQLite
- SQLAlchemy
